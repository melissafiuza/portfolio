# 💻 Portfólio — Melissa Fiuza

> Portfólio pessoal desenvolvido para apresentar minha trajetória, projetos, habilidades e evolução na área de tecnologia.

## 📌 Sobre o projeto

Este projeto reúne informações sobre minha formação, experiências acadêmicas, projetos desenvolvidos e conhecimentos em tecnologia.

A proposta é criar um espaço para apresentar minha evolução como desenvolvedora e reunir projetos desenvolvidos ao longo da minha formação.

## 🎯 Objetivos

* Apresentar meus principais projetos;
* Demonstrar meus conhecimentos em desenvolvimento web;
* Compartilhar minha trajetória acadêmica e profissional;
* Facilitar o acesso aos meus projetos e formas de contato.

## 🛠️ Tecnologias

As tecnologias utilizadas no desenvolvimento do portfólio serão adicionadas conforme o projeto evoluir.
